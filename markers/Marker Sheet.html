InvaderGIS · Cartographic Marker System

Map markers

A unified marker vocabulary across the four data layers. Each layer owns a distinct silhouette so it reads at a glance even when overlapped; the white glyph carries the subtype. Geometry is ported 1:1 from src/design/glyphMarks.tsx; colors are the locked tokens from tokens.ts. Use the Tweaks panel to compare glyph-stroke treatments, then export the set you choose.
